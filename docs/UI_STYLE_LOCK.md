# UI STYLE LOCK — ERP / WMS

이 프로젝트의 UI는 일반 소비자용 웹앱이나 스타트업 SaaS 대시보드처럼
앙증맞고 둥글둥글한 방향으로 디자인하지 않는다.

## 고정 방향

- 전형적인 ERP / WMS / 운영툴
- 직선형 패널과 표
- 작은 또는 0 radius
- 회색계열 Header / Grid
- 높은 정보밀도
- 기능 중심
- 상태색은 제한적으로만 사용
- 그림자/그라디언트/장식 최소화
- 데이터 테이블과 입력 폼이 주인공
- 버튼은 작고 명확하게

## 피해야 할 표현

- 카드가 둥글고 떠 있는 SaaS Dashboard
- pastel card
- oversized icon
- 큰 여백
- 둥근 pill 남발
- playful illustration
- 귀엽고 캐주얼한 색조
- 스티커 메모형 공지
- 모바일 소비자 앱처럼 큰 둥근 CTA

## 관리자 Web

관리자 화면은 데스크톱 업무시스템을 기준으로 한다.

- Sidebar 고정
- Toolbar / Tab / Grid
- 한 화면에 여러 업무정보 표시
- Table Row 단위 조작
- 필요시 Modal보다는 작은 Layer/Panel 우선

## MATE PWA

MATE 화면도 귀여운 모바일 앱이 아니라
산업용 PDA / 현장업무 단말기의 현대화 버전 느낌을 유지한다.

- 큰 터치영역은 유지
- 시각적으로는 직선형
- 정보위계 명확
- 작업상태 / 로케이션 / 시간 강조
- 장식은 최소화

UX 접근성 때문에 필요한 터치크기와
'둥글고 귀여운 UI'는 별개의 문제로 본다.
